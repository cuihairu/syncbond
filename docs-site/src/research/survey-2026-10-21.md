
# Research: short-code pairing & E2E sync landscape

> **Research input, not repo facts.** Everything below summarizes external projects as understood on 2026-10-21; every claim must be re-verified against the linked sources before being treated as a property of this repository. Sources were located by public search on 2026-10-21.

Scope: existing projects that combine short-code pairing with end-to-end encrypted sync, surveyed to position this SDK. Conclusion up front: **every near neighbor is a whole application, not an embeddable core library** — none of them ships a reusable pairing/sync core that another product can embed without adopting the whole app.

## Kith — serverless E2EE device sync

- Source: https://github.com/muhamadjawdatsalemalakoum/kith (README), https://muhamadjawdatsalemalakoum.github.io/kith/
- One-time short pairing code; SPAKE2 derives the group key — the code never crosses the network.
- No account, no cloud: iroh (QUIC) direct device-to-device, mainline-DHT discovery, relay fallback that only forwards ciphertext.
- Automerge CRDT state; per-space keys, epoch-key revocation, XChaCha20-Poly1305 at rest.
- **Gap**: a Rust desktop application (memory/tabs/files). Its mesh-engine crate touches iroh/automerge and is not published as an embeddable, app-agnostic sync library.

## UniClipboard — clipboard sync with invite codes

- Source: https://github.com/UniClipboard/UniClipboard, https://docs.uniclipboard.app/ , https://docs.uniclipboard.app/guides/pairing
- Joining a space: short-lived one-time invite code + space passphrase; PAKE means the joiner proves knowledge of the passphrase without sending it; wrong passphrase fails the handshake.
- XChaCha20-Poly1305 payloads independent of transport — a hostile relay sees only ciphertext; Argon2id for passphrase-derived key material; encrypted at rest.
- Direct P2P first, encrypted relay fallback; connections recover after sleep/network switches.
- **Gap**: a clipboard application (desktop/CLI). The pairing + space-key machinery is embedded in the product, not a standalone core library.

## CrossPaste — cross-device clipboard, pairing v3

- Source: https://github.com/CrossPaste/crosspaste-desktop (see `core/src/commonMain/kotlin/com/crosspaste/pairing/v3/Spake2P256.kt`)
- SPAKE2 over P-256 assembled exactly per RFC 9382: fixed M/N constants, PIN→`w` derivation via HKDF, RFC transcript TT, `Ke` output — with RFC 9382 test-vector conformance and its own pairing-transport interface layer.
- Closest methodological relative to this SDK's protocol layer.
- **Gap**: Kotlin Multiplatform code inside a clipboard desktop app (`internal` visibility); not reusable as a standalone library from Rust/TS.

## SyncDroid-Mesh — phone mesh sync

- Source: named in the 2026-10-21 project survey; public repository not re-located during this write-up (details below are from that survey, not independently verified).
- Six-digit PAKE code pairing; mutual certificate pinning between paired devices.
- **Gap**: whole-application mesh sync; no embeddable core.

## magic-wormhole — the classic PAKE transfer tool

- Source: https://github.com/magic-wormhole/magic-wormhole , docs at https://magic-wormhole.readthedocs.io/
- SPAKE2 over a rendezvous server with human-pronounceable codes (two words + digits); the code authenticates the channel, transfer is E2E.
- Long-standing proof that short-code PAKE works for non-technical users.
- **Gap**: a file/directory transfer tool with its own protocol; not a sync engine, not embeddable as a library.

## WeType cross-device clipboard (independent Rust client)

- Source: https://github.com/mkdir700/wx-ime-sdk
- Independent Rust client for the WeChat input method (WeType) cross-device clipboard — demonstrates demand for WeChat-style short-code sync outside the official app.
- **Gap**: client for a proprietary service; the pairing/sync protocol itself is closed and not embeddable.

## Conclusion of the survey

| Project | Short-code pairing | E2EE | Sync engine | Embeddable core library |
|---|---|---|---|---|
| Kith | SPAKE2 one-time code | yes (QUIC + at rest) | Automerge CRDT | no — whole app |
| UniClipboard | invite code + passphrase (PAKE) | yes (XChaCha20-Poly1305) | clipboard history sync | no — whole app |
| CrossPaste | SPAKE2 P-256 (RFC 9382) | yes | clipboard sync | no — app-internal Kotlin |
| SyncDroid-Mesh | 6-digit PAKE code | yes (cert pinning) | mesh sync | no — whole app |
| magic-wormhole | SPAKE2 short code | yes (transfer) | none (one-shot transfer) | no — standalone tool |
| WeType client | proprietary (WeChat) | proprietary | clipboard sync | no — client for closed service |

This repository's positioning fills that gap: a Rust core library for short-code (PAKE) pairing and E2E encrypted, transport-agnostic sync with pluggable merge, embeddable from any language with a binding — with the business model left entirely to the embedding application.
